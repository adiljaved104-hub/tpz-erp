# QuickBooks Desktop Enterprise 2024 Functional Parity Matrix

**Status date:** 12 Nov 2026
**Reference:** Installed QuickBooks Desktop Enterprise 2024, isolated Peera company copy
**Purpose:** Evidence-led implementation tracker. The Owner-approved TPZ prototype defines visual language; QuickBooks Desktop is the functional reference. This matrix does not claim complete parity.

## Evidence boundaries

- The isolated QuickBooks company connection succeeded, supported qbXML versions were discovered, and initial read-only queries passed (see [QuickBooks discovery plan](quickbooks-enterprise-2024-discovery-plan.md) and [Owner review](accounting-b2-owner-review-20261112.md)). The discovery log does not yet contain transaction samples, report exports, linked-transaction graphs, or a direct screen walkthrough. Those details remain **unverified in the installed company**.
- Intuit help pages below provide documented QuickBooks Desktop workflows, but they do not substitute for observing the installed Enterprise 2024 build and company preferences. Any differences found in the isolated company must be recorded with version and date.
- No SDK/UI writes have been performed. Any controlled write requires explicit Owner approval and must use only the isolated copy.
- TPZ status is based on repository code and tests. “Available” means a native B1 implementation exists; it does not imply verified QuickBooks parity or operational posting.
- Journal posting remains disabled pending explicit Owner activation.
